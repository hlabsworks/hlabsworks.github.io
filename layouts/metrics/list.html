太陽光・蓄電池・ポータブル電源の導入で、今いくら浮いているか

電気代を4つの層で比較しています。L0 = 太陽光・蓄電池・本システムのいずれも 無かった場合（推定）、L1 = 太陽光（9.4kW）のみ導入した場合（推定）、 L2 = 太陽光＋蓄電池（ニチコンESS-H2L1）を導入した場合（推定）、 L3 = 実際に導入している全構成（太陽光＋蓄電池＋ポータブル電源、実測）です。 L0〜L2は「推定」バッジの付いた反実仮想（もしそうしていなかったら／そうしていたら）であり、 系統連系点のエネルギー収支から復元した家庭の真の消費電力（時刻ごとの発電・買電・売電・ 蓄電池充放電の収支から逆算した値）を基に5分単位でシミュレーションしています。表示金額は 「買電額 − 売電収入」（節約額の主指標）で、請求実績単価・FIT売電単価16円/kWhを使用します。 下のボタンで、自宅のFIT期間終了後を想定した卒FIT換算（8円/kWh）にも切り替えられます。 推定層（L0〜L2）が1件も算出できている請求月がまだ無い間は、下のグラフ・累計表は表示せず、 実測（L3）のみの請求額再現（本ページ下部の表）をご覧ください。

推定層（L0〜L2）が算出できていない請求月でも、実測（L3）の買電・売電の出典 （請求実績／公式メーター／センサー計測のいずれを採用したか）はこの表で確認できます。

蓄電池パラメータ（実効容量・変換効率・定格出力）は ニチコンESS-H2L1製品ページ の仕様値を基に、自宅での実測較正値（2026-09-01の充放電積分）で補正しています。太陽光は FIT設備認定どおり9.4kW全量として計算しています。西屋根PVのDC/AC変換効率は未確定のため、 主値100%に加え95%仮定でも計算した不確かさ帯を上表に開示しています（グラフ・累計表は 主値のみ表示）。5分プロファイルデータが請求期間の全日分そろっていない月（coverage<100%）は L0〜L2列を「―」にし、「計測項目不足のため推定不可」として扱います（値を捏造しません）。 蓄電池SOC（期間開始→終了）は請求期間境界での残エネルギーによる最大2〜3%のバイアスがあり、 金額の補正はしていません（注記のみ）。詳細は docs/design/20260905_layer-model-ddr.md（SolarChargeControllerリポジトリ）を参照してください。

請求実績単価による請求額再現（請求期間ベース）

Japan電力 くらしプランS（中部エリア）の請求実績単価を使い、請求期間（毎月2日〜翌月1日）ごとに 実測（太陽光＋蓄電池＋ポータブル電源、上記L3と同じ）の請求額を再現しています。 「反実仮想（太陽光なし）」列は、系統連系点のエネルギー収支から復元した真の家庭負荷（上記L0と同じ）が 請求期間の全日分そろっている月のみ表示し、そろわない月は「計測項目不足のため推定不可」と表示します （旧仕様の消費電力ベースの反実仮想は、逆潮流時に実態の67%程度しか説明できないことが判明したため廃止しました）。 売電収入は自宅が現在 FIT 期間中のため FIT 単価で計算した「FIT実態」と、 読者の多くが想定するであろう卒FIT想定単価で計算した「卒FIT換算」を併記します。

発電・買電・売電の集計元は {{ .power_history_since }} から連続測定している自宅の電力計測値です。 蓄電池（ニチコン）への充電量は {{ .nichicon_data_since }} から記録しています。 ポータブル電源（EcoFlow）への充電量は直近ローリング14日分のみ保持しており（{{ .ecoflow_data_since }} 〜が現在の範囲）、 それより古い日付では欠測（表示上は「―」）となります。「蓄電池+ポタ電 充電」は両者を合算した値のため、 ポタ電側が欠測の期間は蓄電池分のみの数値です。
月次の節約額試算（簡易・暦月集計） = 自家消費分（太陽光発電 − 売電）× 買電単価 {{ .buy_price_yen_per_kwh }}円/kWh + 売電分 × 売電単価 {{ .sell_price_yen_per_kwh }}円/kWh （{{ .buy_sell_price_effective_month }} 時点の tariff.json から自動算出。{{ .buy_sell_price_source }}）。
「請求実績単価による請求額再現」は請求期間（毎月2日〜翌月1日）の全日データが揃っている月のみ表示しています （直近月やデータ欠測のあった月は除外されます）。容量拠出金は請求明細PDFで確定した実額を計上しています。 請求PDF未取得の月は集計対象外です。実際の契約内容・料金改定・税制変更により本試算と実請求額は乖離する場合が あります。
売電量は東京電力パワーグリッドの購入実績（公式メーター）を採用しており、パワコン計測（センサー値）との差は 欠測のない月で±2%以内です。公式メーター実績が未取得の月はセンサー計測値で代替表示します。買電量も同様に Japan電力の請求明細PDF実績を優先採用し（買電センサーは量子化・不感帯で系統的に過小のため）、請求実績が 未取得の月はセンサー計測値で代替表示します。
